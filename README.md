# 鍵上樂理

以 MIDI 鍵盤學習樂理、指法與和弦的成人互動課程（原型）。純前端靜態網頁，進度存在瀏覽器 localStorage。

## 使用

- 建議使用桌機的 Chrome 或 Edge（Safari 不支援 Web MIDI，只能用電腦鍵盤／滑鼠）。
- 第一次連上 MIDI 鍵盤時會要求校準：依序按最左、最右的鍵。
- 沒有 MIDI 鍵盤時：電腦鍵盤 Z 列為 C3–B3，Q 列為 C4–C5；也可用滑鼠點琴鍵。

## 課程

每課固定五段：暖身複習 → 新概念 → 引導練習 → 實際曲目 → 總結評分。目前可上課的有：

- 入門：1–7 全部（鍵盤、運指、節奏、五線譜、音階穿指、三和弦、哈農手指練習）
- 進階：1–11 全部（音程、大小調、七和弦、轉位與聲部進行、和聲功能與 ii–V–I、借用和弦、次屬和弦、三全音代理、伴奏型、減七與經過減和弦、延伸和弦 9／11／13）

運指與和弦應用的完整對照與缺口見 [docs/CURRICULUM.md](docs/CURRICULUM.md)。

## 功能

- 即時回饋、整課星等、間隔複習（Leitner）與每日複習、練習日曆與連續天數、中途離開續上、進度匯出／匯入。
- 多個分頁同時開啟時進度不會互相覆蓋。
- 可安裝成網頁 App（manifest＋離線快取）。

## 本機執行

任何靜態伺服器皆可，例如：

```bash
npx serve .
```

Web MIDI 需要 https 或 localhost。
