# 鍵上樂理

以 MIDI 鍵盤學習樂理、指法與和弦的成人互動課程（原型）。純前端靜態網頁，進度存在瀏覽器 localStorage。

## 使用

- 建議使用桌機的 Chrome 或 Edge（Safari 不支援 Web MIDI，只能用電腦鍵盤／滑鼠）。
- 第一次連上 MIDI 鍵盤時會要求校準：依序按最左、最右的鍵。
- 沒有 MIDI 鍵盤時：電腦鍵盤 Z 列為 C3–B3，Q 列為 C4–C5；也可用滑鼠點琴鍵。

## 課程

每課固定五段：暖身複習 → 新概念 → 引導練習 → 實際曲目 → 總結評分。目前可上課的有：

- 入門：1–8 全部（鍵盤、運指、節奏、五線譜、音階穿指、三和弦、哈農手指練習、順階和弦）
- 進階：1–11 全部（音程、大小調、七和弦、轉位與聲部進行、和聲功能與 ii–V–I、借用和弦、次屬和弦、三全音代理、伴奏型、減七與經過減和弦、延伸和弦 9／11／13）

另有不需要琴鍵的「樂理練習」：讀譜（高音、低音譜號）、音符與休止符、調號、看譜數音程、看譜認和弦、聽力（音程、和弦性質、音階）、調性觀念，以及吉他指板記憶（空弦、根音弦、路標格、看位置說音名、在弦上找音、一個音名走遍六弦、找出所有同名音、八度位置），並附〈指板記憶指引〉：整理吉他教師的建議與四週練法；還有吉他和弦指形（認開放和弦、指形裡的 R／3／5、推算 E 型與 A 型橫按位置、看指形說和弦、移動一個音把大三和弦改成小、7、maj7、CAGED 五種指形），附〈和弦指形指引〉與圖解的〈CAGED 系統詳解〉。點選作答，手機直式就能用；在手機上會排在首頁前面。

運指與和弦應用的完整對照與缺口見 [docs/CURRICULUM.md](docs/CURRICULUM.md)。

## 功能

- 即時回饋、整課星等、間隔複習（Leitner）與每日複習、練習日曆與連續天數、中途離開續上、進度匯出／匯入。
- 先聽再看（聲音先於符號）：每課的「實際曲目」先用耳朵學。旋律一句一句聽完彈回來，和弦曲目聽出每個和弦的最低音；這時不顯示音名、和弦名或譜，琴鍵也不會跟著示範亮。之後才對照音名與譜彈。這一步不計分，可按「直接看音名」略過。
- 即興與創作：入門 1、2、5、6、8 與進階 2、5 的曲目段最後，有在伴奏循環上即興（只亮出可用的音，例如黑鍵五聲、C 大調、A 小調五聲、ii–V–I），或用指定的幾個音編一句旋律、結束在主音並播放出來。不計分。
- 課程與今日複習可按「上一頁」回到前一個畫面（可跨段落、也可從段落結果退回）；重做的題目照第一次作答計分。
- 多個分頁同時開啟時進度不會互相覆蓋。
- 響應式版面：手機直式適合樂理練習；彈奏課程建議把手機轉成橫向，25 鍵一次放下、題目壓縮成一兩行（直拿進入時會提示，可在設定關閉）。吉他指板隨螢幕方向自動直放或橫放。
- 可安裝成網頁 App（manifest＋離線快取）。

## 本機執行

任何靜態伺服器皆可，例如：

```bash
npx serve .
```

Web MIDI 需要 https 或 localhost。
