# 課程大綱與涵蓋檢查

鍵上樂理的教材必須涵蓋 **運指（指法）** 與 **各種和弦應用**（含借用和弦、三全音代理等技巧）。本文件把每個主題對應到課程，並標出目前狀態，作為後續編寫的依據。

- 「可上課」：已有完整五段（暖身 → 新概念 → 引導練習 → 實際曲目 → 總結評分）與評分。
- 「製作中」：已列在課程地圖，內容尚未編寫。
- 所有練習的音域都限制在 25 鍵（C3–C5）內。

## 判定方式

- 和弦：同時按下（或 1.5 秒內依序按下）就算一個和弦，任何轉位、任何八度都可以。殼式和聲只要求根音、三音、七音。標示「最低音要彈根音」的題目會檢查低音。
- 聽力：單音「聽→彈」，和弦性質、借用和弦、三全音代理則用聽後選擇。
- 每個題目都屬於一個概念，答錯的概念會排進隔天的「今日複習」。
