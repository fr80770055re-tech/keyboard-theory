# 課程大綱與涵蓋檢查

鍵上樂理的教材必須涵蓋 **運指（指法）** 與 **各種和弦應用**（含借用和弦、三全音代理等技巧）。本文件把每個主題對應到課程，並標出目前狀態，作為後續編寫的依據。

- 「可上課」：已有完整五段（暖身 → 新概念 → 引導練習 → 實際曲目 → 總結評分）與評分。課程中可按「上一頁」回看前一個畫面；退回重做的題目不改變分數（照第一次作答）。
- 「製作中」：已列在課程地圖，內容尚未編寫。
- 所有練習的音域都限制在 25 鍵（C3–C5）內。

系統判斷不了用哪根手指，所以運指靠三件事：琴鍵與音符上的指號、只能用正確指法才彈得順的練習設計，以及說明裡的自我檢查提示。

每個有提示的題目都標指號：旋律與音階逐音標示；和弦標每根手指（左手低音一律 5 指，右手原位與第二轉位 1-3-5、第一轉位 1-2-5；從 C 換到 F/C 時用 1-4-5）；殼式和聲右手依兩音距離用 1-3、1-4 或 1-5；找單音的題目依手的位置（右手 C 位置與 G 位置、左手 C 位置與中央 C 位置）；音程題以拇指放在出發音、依度數用 2–5 指。只有「找出鍵盤上所有的 C」這類題目不標指號。

## 樂理練習（不用琴鍵）

給手機直式或手邊沒有琴鍵時使用，每輪約 3–4 分鐘，題目每輪隨機產生，點選作答，答錯的概念排進今日複習。程式在 `js/lessons/drills.js`。

| 類別 | 練習 | 概念 |
|---|---|---|
| 讀譜 | 高音譜號（C4–A5）、低音譜號（E2–C4）、兩種混合 | read-treble、read-bass |
| 符號 | 音符與休止符的拍數（含附點）；調號（三個升降記號以內，含關係小調） | note-values、key-sig |
| 看譜分析 | 音程度數（先後與疊在一起）；三和弦名稱與原位／轉位 | interval-read、chord-read |
| 聽力 | 音程、大小減三和弦與七和弦、大小調音階 | interval-ear、triad-quality、quality-ear、scale-ear |
| 觀念 | 關係與同主音大小調、和聲小調、順階級數 | key-relations、diatonic-roman |
| 吉他指板 | 空弦音名；根音弦（第 6、5 弦）；路標格（空弦、第 3/5/7/9/12 格）；看位置說音名（自然音／含升降）；在指定弦上找音；一個音名走遍六弦（第 1–12 格，不用空弦）；找出所有同名音；八度位置（隔一條弦 +2 格，跨 B 弦 +3 格） | fret-open、fret-name、fret-find、fret-all、fret-octave |

吉他指板為標準調弦、空弦到第 12 格（`js/fretboard.js`、`js/lessons/guitar.js`）。手機上找位置的題目把指板直放（像和弦圖，低音 E 在左），每一格都是夠大的點擊目標；看位置說音名的題目與寬螢幕則橫放（像六線譜，高音 E 在上）。點指板會聽到該音。

首頁「吉他指板」下方有〈指板記憶指引〉（`js/lessons/guides.js`）：整理多位吉他教師與一項練習研究的共同建議，分成八個原則與四週練法，每一步都連到對應練習，並列出資料來源。辨認類的吉他練習結束時會顯示平均每題秒數，目標是 2 秒內（正確率穩定後才看速度）。

## 判定方式

- 和弦：同時按下（或 1.5 秒內依序按下）就算一個和弦，任何轉位、任何八度都可以。殼式和聲只要求根音、三音、七音；延伸和弦只要求根音、三音、七音與該延伸音（5 度可省）。標示「最低音要彈根音」的題目，以及轉位、斜線和弦（C/E 等）會檢查最低音。
- 聽力：單音「聽→彈」；音程是先聽中央 C 再聽第二個音，然後彈出第二個音。音程、音階種類、轉位、和弦性質、借用和弦、三全音代理、減七與延伸音則用聽後選擇。
- 每個題目都屬於一個概念，答錯的概念會排進隔天的「今日複習」。

## 建議的下一步

1. 轉調（調性轉換）：共同和弦轉調、用新調的屬七和弦帶入。
2. 變化屬和弦（♭9、♯9、♯5、alt）與小調的 ii–V–i（iiø7–V7♭9–i）。
3. 運指：縮指與大跳換位；哈農第 3 號以後、徹爾尼練習曲（需指定作品號，並改編進 C3–C5）。
4. 小調音階目前只教 A 小調與 A 大調（只用升記號，畫面上的音名拼法才會正確）。要教降號調，得先讓音名顯示支援降記號。
